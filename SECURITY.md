# Security Policy

## Supported versions

Security fixes are applied to the latest released RevisionGraph version.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories for this repository.
Do not open a public issue for a vulnerability that has not yet been fixed.

RevisionGraph has no analytics or network service. Reports involving command execution, malicious
repository data, unsafe reference handling, or IntelliJ Platform integration are still considered
security-sensitive and are welcome.
